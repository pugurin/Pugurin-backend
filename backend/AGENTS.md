# backend/AGENTS.md

부산 부동산 플랫폼의 **백엔드**를 개발하는 코딩 에이전트용 가이드입니다.
전체 개요·공통 규칙은 루트 [`../AGENTS.md`](../AGENTS.md)를 참고하세요.

---

## 1. 역할

- 실거래가를 **배치로 수집·정제·저장(ETL)** 하고,
- 지도 영역·필터로 **조회하는 REST/JSON API**를 제공하며,
- 위치/지번의 **토지이용계획을 온디맨드 조회 후 캐싱**하고,
- **사용자/공인중개사 계정을 구분하는 인증**을 제공하고,
- 사용자 ↔ 중개사(또는 사용자 간) **실시간 채팅**을 중계하고,
- **광고 노출**을 관리한다.
- 프론트(앱)는 이 API만 소비한다 → **API-first**. 백엔드는 프론트 구현에 의존하지 않는다.

## 2. 기술 스택

| 항목             | 선택                                              |
| ---------------- | -------------------------------------------------- |
| 프레임워크       | FastAPI                                            |
| DB               | PostgreSQL + PostGIS                               |
| ORM/마이그레이션 | SQLAlchemy + Alembic (예정)                        |
| 인증             | JWT 기반, 사용자/중개사 role 구분 (상세 설계 예정) |
| 실시간 통신      | FastAPI WebSocket (채팅, 상세 설계 예정)           |
| 외부 데이터      | 공공데이터포털 실거래가 API, VWorld API            |
| 실행/배포        | Docker                                             |

## 3. 레이어 구조

```
routers/   HTTP/WS 진입점. 요청 검증·직렬화만. 외부 API 직접 호출 금지.
services/  도메인 로직(조회 필터, 통계 계산, 분석 조합, 채팅 라우팅, 광고 노출 로직).
repositories/  DB 접근(PostGIS 공간 쿼리 포함).
adapters/  외부 API 어댑터(실거래가/ VWorld) + mock 구현.
ingestion/  ETL 잡(수집·정제·지오코딩·적재).
auth/      인증/인가(JWT 발급·검증, role 기반 권한).
models/    SQLAlchemy 모델 / Pydantic 스키마.
core/      설정(config), DB 세션, 공통 유틸.
```

호출 방향: `routers → services → repositories / adapters`. 역방향 의존 금지.

## 4. 백엔드 규칙

1. **API 키 없이도 개발·테스트 가능해야 한다.** 외부 접근은 `adapters/` 인터페이스 뒤에 두고, 기본으로 mock/샘플 구현을 제공한다. 실 키는 환경변수 주입, 하드코딩 금지.
2. **비밀값 커밋 금지.** `.env`는 `.gitignore`, `.env.example`만 커밋.
3. **공간 데이터는 PostGIS로.** 좌표는 `geometry(Point, 4326)` + GiST 인덱스. 영역 조회는 `ST_Within`/`ST_Intersects`, 반경은 `ST_DWithin`.
4. **부산 범위 밖 데이터는 적재하지 않는다.** 지역코드(16개 구·군)·매물 유형은 설정으로 관리.
5. **ETL은 멱등(idempotent)** 해야 한다. 같은 기간 재수집 시 중복 적재 없이 upsert.
6. **인증은 role 기반으로 분리한다.** 일반 사용자와 공인중개사 계정의 권한 범위(매물 등록 가능 여부 등)를 명확히 구분한다.
7. **채팅은 상태 비저장 게이트웨이로 취급한다.** 메시지 영속화는 DB, WebSocket 연결은 세션 레이어에서만 관리 — 도메인 로직과 분리.
8. **TDD.** 라우터·서비스·리포지토리는 테스트 우선. 외부 API는 mock으로 대체.
9. 응답·주석·문서는 한국어. 에러는 일관된 JSON 형식으로 반환.
