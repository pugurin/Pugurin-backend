# 기능명세서 (Pugurin Backend) — v1.0

부산 부동산 지도 서비스의 **기능 단위 명세**입니다. "무엇을, 누가, 어떤 규칙으로" 하는지를 정의합니다.
요청·응답 형식은 [`API_SPEC.md`](./API_SPEC.md), 구현 규칙은 [`../backend/AGENTS.md`](../backend/AGENTS.md)를 참고하세요.

- **기준 문서:** API 명세 v0.3
- **작업 추적:** 각 기능의 `이슈` 칸은 [GitHub Issues](https://github.com/pugurin/Pugurin-backend/issues) 번호

---

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스 | 부산 지도 위에 실거래가를 단지 단위로 보여주고, 토지 정보를 쉬운 말로 설명하며, 공인중개사와 전화·채팅으로 연결 |
| 대상 지역 | 부산광역시 16개 구·군 |
| 매물 유형 | 아파트, 오피스텔, 연립·다세대(빌라), 토지 |
| 거래 유형 | 매매(중심), 전세, 월세 |
| 핵심 사용자 | 40~50대 실구매 수요자. 대부분 로그인 없이 조회 |
| 범위 밖 | 가격 예측·투자 추천, 사용자 간 채팅·직거래, 자체 광고 서버 |

## 2. 사용자 유형

| 유형 | 코드 | 설명 | 할 수 있는 일 |
|---|---|---|---|
| 비로그인 사용자 | `guest` | 앱 설치 후 로그인하지 않은 사용자 | 지도·검색·단지·토지·분석·용어 조회, 중개사 조회·전화 |
| 일반 사용자 | `buyer` | 카카오·네이버로 가입한 사용자 | guest 기능 + 관심 등록, 알림, 중개사 채팅, 신고, 중개사 승격 신청 |
| 중개사 | `agent` | 검증을 통과한 공인중개사 | buyer 기능 + 채팅 응대, 프로필 관리, 매물 등록(3차) |
| 관리자 | `admin` | 내부 운영자 | 중개사 심사, 신고 처리, 용어 관리 |
| 시스템 | `system` | 배치·자동 처리 | 실거래가 수집, 알림 발송, 만료 처리 |

## 3. 단계 구분

| 단계 | 목표 | 로그인 |
|---|---|---|
| **1차 (MVP)** | 공공데이터만으로 쓸 만한 지도 | 불필요 |
| **2차** | 사용자·중개사 연결 (로그인, 중개사, 채팅, 알림) | 필요 |
| **3차** | 중개사 매물 플랫폼 | 필요 |

## 5. 기능 상세

### 5.1 데이터 수집

#### F-DATA-01 실거래가 정기 수집
- **설명:** 공공데이터포털 실거래가 7종(아파트·오피스텔·연립다세대 매매/전월세, 토지 매매)을 매일 1회 수집해 저장한다.
- **규칙**
  - 부산 16개 구·군만 수집한다.
  - 같은 거래를 여러 번 수집해도 **한 건만** 저장된다(중복 없음).
  - 신고 기한(30일)과 정정 신고 때문에 **최근 3개월은 매번 다시 수집**한다.
  - 금액은 원 단위로 저장한다(원천은 만원 단위).
  - 거래유형(중개거래/직거래)을 함께 저장한다.
- **예외**
  - 외부 API 일일 호출 한도 초과 → 남은 작업은 다음 실행으로 미룬다.
  - 외부 API 장애 → 실행 기록에 실패로 남기고, 기존 데이터는 그대로 서비스한다.
- **API / 이슈:** 내부 배치 / #6 #7

#### F-DATA-02 해제(취소) 거래 반영
- **설명:** 계약 후 해제 신고된 거래를 표시하고 통계에서 뺀다.
- **규칙**
  - 해제된 거래는 지도·통계·기본 목록에 **나오지 않는다**.
  - 거래 목록에서 `해제 거래 포함`을 켜면 "해제" 표시와 함께 보인다.
- **이유:** 일명 "집값 띄우기" 허위 신고 거래가 시세를 왜곡하지 않게 한다.
- **API / 이슈:** 내부 배치, `GET /transactions?include_cancelled=` / #7

#### F-DATA-03 위치 변환 및 단지 묶기
- **설명:** 거래의 지번 주소를 좌표로 바꾸고, 아파트·오피스텔·빌라 거래를 단지·건물 단위로 묶는다.
- **규칙**
  - 좌표는 서버가 VWorld로 계산한다.
  - 지번이 가려진 거래(토지 등, 확인 필요)는 **동네 중심점**에 두고, 동네 통계에만 반영한다.
  - 단지별 평형 목록을 만들고, 가능하면 공급면적 기준 평형도 계산한다.
- **예외:** 좌표 변환 실패 → 실패 목록에 남기고 다음 실행 때 다시 시도한다.
- **API / 이슈:** 내부 배치 / #8

#### F-DATA-04 데이터 기준일 안내
- **설명:** 실거래가를 보여주는 모든 화면에 "언제 기준 데이터인지"를 함께 제공한다.
- **규칙**
  - 모든 실거래가 응답에 마지막 수집 완료 시각(`data_as_of`)을 넣는다.
  - "최근 30일 거래는 아직 신고되지 않았을 수 있음" 안내 여부를 함께 준다.
- **API / 이슈:** 공통 응답 `meta` / #7

### 5.2 지도

#### F-MAP-01 지도에서 실거래가 보기
- **설명:** 지도 화면에 보이는 영역의 실거래가를 마커로 보여준다. 앱을 켜면 가장 먼저 보이는 화면이다.
- **규칙**
  - 지도를 멀리서 보면 **구 단위**, 가까이 가면 **동 단위**, 더 가까이 가면 **단지·필지 단위**로 보여준다. 단계는 서버가 정한다.
  - 단지 마커에는 **최근 거래가, 평형, 계약일**을 표시한다.
  - 구·동 마커에는 **거래 건수와 평당가 중위값**을 표시한다.
  - 한 번에 최대 500개 마커. 넘으면 한 단계 넓은 단위로 묶는다.
  - 해제 거래는 제외한다.
- **예외**
  - 지도 영역·줌 누락 → 입력 오류
  - 부산 밖 영역 → 빈 결과
- **API / 이슈:** `GET /map/markers` / #9

#### F-MAP-02 지도 필터
- **설명:** 지도에 보일 거래를 조건으로 거른다.
- **필터 항목**

| 항목 | 선택지 | 기본값 |
|---|---|---|
| 매물 유형 | 아파트 / 오피스텔 / 빌라 / 토지 중 **하나** | (필수) |
| 거래 유형 | 매매 / 전세 / 월세 | 매매 |
| 기간 | 최근 1~60개월 | 12개월 |
| 가격 | 매매가 / 보증금 / 월세 (거래 유형에 맞게) | 전체 |
| 면적 | 평 단위 범위 | 전체 |
| 직거래 제외 | 켜기/끄기 | 끄기 |

- **규칙**
  - 매물 유형은 **한 번에 하나만** 고른다(아파트와 토지 평당가를 섞으면 의미가 없음).
  - 토지는 **매매만** 선택할 수 있다.
- **API / 이슈:** `GET /map/markers` / #9

#### F-MAP-03 평 단위 표시
- **설명:** 모든 면적을 ㎡와 **평**으로 함께 제공한다.
- **규칙**
  - 1평 = 3.3058㎡, 평은 소수 첫째 자리까지 표시한다.
  - 가격은 **평당가** 기준으로 비교한다.
  - 아파트는 사람들이 흔히 말하는 "34평"(공급면적 기준)을 가능하면 함께 보여준다.
- **API / 이슈:** 전 응답 공통 / #9 #10

### 5.3 검색

#### F-SRCH-01 단지·주소·동네 통합 검색
- **설명:** 검색창 하나로 단지명("해운대아이파크"), 주소("우동 1407"), 동네("해운대구 우동")를 찾는다. 결과를 누르면 지도가 그 위치로 이동한다.
- **규칙**
  - 2글자 이상 입력해야 검색한다.
  - 최대 30개 결과. 단지 → 동네 → 주소 순으로 보여준다.
  - 부산 밖 결과는 제외한다.
- **API / 이슈:** `GET /search` / #11

### 5.4 단지·실거래가

#### F-CPX-01 단지 정보 보기
- **설명:** 단지 마커를 누르면 단지 이름, 주소, 준공 연도, 세대수, 평형 목록을 보여준다.
- **API / 이슈:** `GET /complexes/{id}` / #10

#### F-CPX-02 단지 거래 이력 보기
- **설명:** 단지의 거래를 최신순으로 보여준다(가격, 평형, 층, 계약일, 중개/직거래).
- **규칙:** 정렬은 최신순(기본), 가격 낮은순, 가격 높은순. 한 페이지에 20건.
- **API / 이슈:** `GET /complexes/{id}/transactions` / #10

#### F-CPX-03 단지 시세 추이 보기
- **설명:** 단지의 월별 평당가 추이를 그래프용 데이터로 제공한다.
- **규칙**
  - 기본 3년. **중위값** 기준(극단적으로 싸거나 비싼 거래의 영향을 줄임).
  - 한 달 거래가 3건 미만이면 그 달은 값을 비운다.
  - 해제 거래는 제외, 직거래 제외 옵션이 있다.
- **API / 이슈:** `GET /complexes/{id}/stats` / #10

#### F-TRX-01 거래 목록 보기
- **설명:** 지도 대신 목록으로 거래를 본다(지도 영역 또는 지역 기준).
- **예외:** 지도 영역과 지역을 둘 다 안 주면 입력 오류.
- **API / 이슈:** `GET /transactions`, `GET /transactions/{id}` / #10

#### F-TRX-02 지역(구·동) 통계 보기
- **설명:** 구·동 단위의 평당가 중위값, 거래 건수, 월별 추이를 제공한다.
- **API / 이슈:** `GET /stats/regions/{region_code}` / #10

### 5.5 토지

#### F-LAND-01 지도 클릭으로 토지 정보 보기
- **설명:** 지도에서 땅을 누르면 그 필지의 정보를 보여준다.
- **제공 정보:** 지번 주소, 지목(대·전·답 등), 면적(㎡·평), 공시지가, 도로 접면, 모양, 용도지역, 규제 목록
- **규칙**
  - 같은 필지는 30일 동안 저장해 둔 결과를 쓴다(외부 호출 절약).
  - 부산 밖을 누르면 입력 오류.
- **예외:** VWorld 장애 + 저장된 결과 없음 → "토지 정보를 잠시 불러올 수 없음"으로 응답하고 **지도는 계속 쓸 수 있게** 한다.
- **API / 이슈:** `GET /parcels/lookup`, `GET /parcels/{pnu}` / #12

#### F-LAND-02 건폐율·용적률 한도 안내
- **설명:** 이 땅에 건물을 얼마나 넓고 높게 지을 수 있는지(건폐율·용적률 한도)를 보여준다.
- **규칙:** 한도는 **부산광역시 도시계획 조례**의 용도지역별 기준으로 계산하고, 출처를 함께 표시한다.
- **API / 이슈:** `GET /parcels/{pnu}` 의 `zoning` / #12

#### F-LAND-03 토지 규제 쉬운 설명
- **설명:** "가축사육제한구역" 같은 규제 이름마다 한 문장 쉬운 설명을 붙인다.
- **예:** 가축사육제한구역 → "소·돼지 등 가축을 키우는 시설을 지을 수 없어요."
- **규칙:** 관련 용어 해설(F-GLOS)로 바로 이동할 수 있게 용어 ID를 함께 준다.
- **API / 이슈:** `GET /parcels/{pnu}` 의 `restrictions` / #12

### 5.6 분석

#### F-ANAL-01 단지 분석
- **설명:** 단지 시세 추이를 **같은 동네 전체 추이와 비교**하고, 단지가 속한 땅의 용도지역을 요약한다.
- **API / 이슈:** `GET /analysis/complexes/{id}` / #13

#### F-ANAL-02 토지 분석
- **설명:** 필지 정보 + 주변 500m 안 같은 지목 토지의 평당가 추이 + 조례 기준으로 **지을 수 있는 최대 규모**(단순 계산)를 보여준다.
- **예:** "대지 460평 기준 건축면적 최대 약 276평, 연면적 최대 약 1,150평"
- **규칙**
  - "오를 것이다", "사세요" 같은 **예측·권유 문구는 쓰지 않는다.**
  - "참고용이며 실제 건축 가능 여부는 관할 구청 확인 필요" 안내를 항상 붙인다.
- **API / 이슈:** `GET /analysis/parcels/{pnu}` / #13

### 5.7 용어 해설

#### F-GLOS-01 용어 목록·검색
- **설명:** 부동산 용어(건폐율, 용적률, 공시지가, 전용면적 등)를 목록으로 보고 검색한다.
- **규칙**
  - 용어마다 **한 줄 설명**(말풍선용)과 **자세한 설명**(상세 화면용), 예시를 둔다.
  - 한 줄 설명은 40~50대가 한 번에 이해할 수 있는 말로 쓴다.
- **API / 이슈:** `GET /glossary`, `GET /glossary/{term_id}` / #14

#### F-GLOS-02 화면 속 용어 설명 연결
- **설명:** 토지·단지 화면의 어려운 용어를 누르면 해당 용어 설명을 보여준다.
- **규칙:** 토지·단지 응답에 관련 용어 ID 목록을 넣어 앱이 연결한다(별도 추천 기능 없음).
- **API / 이슈:** `glossary_term_ids` 필드 / #14

### 5.8 계정

#### F-AUTH-01 소셜 로그인·가입
- **설명:** 카카오 또는 네이버 계정으로 로그인한다. 처음이면 자동으로 가입된다.
- **규칙**
  - 이메일·비밀번호 가입은 제공하지 않는다.
  - 처음 가입할 때 **이용약관·개인정보 처리 동의**가 필수다.
  - 가입하면 일반 사용자(`buyer`)가 된다.
- **예외:** 필수 동의 누락 → 입력 오류 / 소셜 인증 실패 → 인증 오류
- **API / 이슈:** `POST /auth/oauth/{provider}` / #16

#### F-AUTH-02 로그인 유지
- **설명:** 한 번 로그인하면 14일 동안 다시 로그인하지 않아도 된다.
- **규칙**
  - 접근 토큰은 30분, 갱신 토큰은 14일 유효하다.
  - 갱신할 때마다 새 갱신 토큰을 발급하고 이전 것은 폐기한다.
  - 폐기된 토큰이 다시 쓰이면(탈취 의심) 그 사용자의 **모든 기기를 로그아웃**시킨다.
- **API / 이슈:** `POST /auth/refresh` / #16

#### F-AUTH-03 로그아웃
- **설명:** 현재 기기에서 로그아웃하고, 이 기기로 가던 푸시 알림도 끊는다.
- **API / 이슈:** `POST /auth/logout` / #16

#### F-AUTH-04 내 정보 보기·수정
- **설명:** 닉네임, 역할, 중개사 신청 상태, 알림 설정을 보고 닉네임을 바꾼다.
- **API / 이슈:** `GET /users/me`, `PATCH /users/me` / #16

#### F-AUTH-05 회원 탈퇴
- **설명:** 계정을 삭제한다.
- **규칙**
  - 개인정보는 **즉시 파기(익명화)** 하고, 법으로 보관해야 하는 것만 따로 보관한다.
  - 상대방 채팅 화면에는 "탈퇴한 사용자"로 표시된다.
  - 같은 소셜 계정으로 **다시 가입할 수 있다**(이전 기록과 연결하지 않음).
  - 중개사가 탈퇴하면 그 중개사의 매물은 즉시 숨긴다.
- **API / 이슈:** `DELETE /users/me` / #16

### 5.9 중개사

#### F-AGT-01 중개사 승격 신청
- **설명:** 일반 사용자가 사무소 정보(상호, 대표자, 사업자등록번호, 중개사무소 등록번호, 주소, 전화)를 입력해 중개사 계정으로 바꿔 달라고 신청한다.
- **규칙**
  - 로그인한 일반 사용자만 신청할 수 있다.
  - 사무소 좌표는 서버가 주소로 계산한다.
  - 이미 심사 중인 신청이 있으면 다시 신청할 수 없다.
- **흐름:** 가입(buyer) → 로그인 → (필요 시 서류 업로드) → 신청 → 자동 검증(F-AGT-02) → 통과 시 즉시 승인 / 실패 시 관리자 심사(F-ADM-01)
- **API / 이슈:** `POST /agents/me/application`, `GET /agents/me/application` / #17

#### F-AGT-02 중개사 자동 검증
- **설명:** 신청 정보를 공공 API로 확인해 사람이 보지 않고도 승인한다.
- **규칙**
  - 국세청: 사업자가 **계속 영업 중**인지 확인
  - VWorld 중개업자 조회: **등록번호·상호·대표자**가 일치하는지 확인
  - 모두 통과 → 즉시 승인 / 하나라도 실패 → 심사 대기, 자격증 서류 필수
- **API / 이슈:** 내부 처리 / #17

#### F-AGT-03 주변 중개사 찾기
- **설명:** 지도 위치 기준 반경 안의 중개사무소를 보여준다.
- **규칙**
  - 반경 기본 1km, 최대 5km (미터 단위로 정확히 계산)
  - **승인된 중개사만** 보인다.
- **API / 이슈:** `GET /agents` / #17

#### F-AGT-04 중개사 프로필·전화 걸기
- **설명:** 사무소명, 대표자, 등록번호, 주소, 전화번호, 소개, 채팅 응답률·응답 시간을 보여준다. **전화 걸기** 버튼으로 바로 연결한다.
- **규칙:** 미승인 중개사는 "찾을 수 없음"으로 처리한다.
- **API / 이슈:** `GET /agents/{id}` / #17

#### F-AGT-05 중개사 프로필 수정
- **설명:** 승인된 중개사가 사무소 소개, 사진, 주로 다루는 지역을 수정한다.
- **API / 이슈:** `PATCH /agents/me/profile` / #17

### 5.10 파일

#### F-UPL-01 사진·서류 업로드
- **설명:** 매물 사진, 프로필 사진, 중개사 자격 서류를 올린다.
- **규칙**
  - 이미지(jpeg/png/webp)와 문서(pdf/jpeg/png) 모두 최대 10MB
  - 자격 서류는 **관리자만** 볼 수 있다(올린 본인도 다시 볼 수 없음).
  - 이미지는 썸네일을 자동으로 만든다.
  - 올리고 24시간 안에 어디에도 쓰이지 않은 파일은 자동 삭제한다.
- **API / 이슈:** `POST /uploads`, `POST /uploads/{id}/complete`, `GET /uploads/{id}` / #18

### 5.11 관심

#### F-INT-01 관심 단지 등록
- **설명:** 단지를 관심 목록에 넣고, 새 거래가 생기면 알림을 받는다(F-NOTI-03).
- **규칙:** 여러 번 눌러도 한 번만 등록된다. 목록에는 단지별 최근 거래를 함께 보여준다.
- **API / 이슈:** `PUT/DELETE/GET /interests/complexes` / #19

#### F-INT-02 관심 지역 등록

- **규칙:** 최대 10개
- **API / 이슈:** `PUT/DELETE/GET /interests/regions` / #19

### 5.12 채팅

#### F-CHAT-01 중개사에게 문의 시작
- **설명:** 단지·토지·매물 화면에서 중개사에게 채팅으로 문의한다.
- **규칙**
  - **일반 사용자 → 승인된 중개사** 방향으로만 시작할 수 있다(중개사가 먼저 말 걸기 불가, 스팸 방지).
  - 같은 중개사에게 같은 단지·매물로 다시 문의하면 **기존 채팅방으로 이어진다.**
  - 사용자끼리 채팅은 제공하지 않는다.
- **예외:** 미승인·탈퇴 중개사 → 찾을 수 없음
- **API / 이슈:** `POST /chat/rooms` / #20

#### F-CHAT-02 채팅방 목록
- **설명:** 내 채팅방을 최근 대화순으로 보여준다(상대 이름, 마지막 메시지, 안 읽은 수).
- **API / 이슈:** `GET /chat/rooms`, `GET /chat/rooms/{id}` / #20

#### F-CHAT-03 실시간 메시지 주고받기
- **설명:** 메시지를 보내면 상대에게 바로 전달된다.
- **규칙**
  - 메시지는 1~1,000자
  - 앱이 실시간 연결을 잃어도 **일반 전송으로 보낼 수 있다.**
  - 같은 메시지를 재전송해도 **한 번만 저장**된다.
  - 1초에 5개까지만 보낼 수 있다.
  - 상대가 앱을 안 보고 있으면 푸시 알림이 간다(F-NOTI-04).
- **API / 이슈:** `WS /ws/chat`, `POST /chat/rooms/{id}/messages` / #20 #21

#### F-CHAT-04 이전 메시지 보기
- **설명:** 위로 스크롤하면 이전 메시지를 30개씩 더 불러온다.
- **API / 이슈:** `GET /chat/rooms/{id}/messages` / #20

#### F-CHAT-05 읽음 표시
- **설명:** 상대가 메시지를 읽으면 실시간으로 읽음 표시가 된다.
- **API / 이슈:** `POST /chat/rooms/{id}/read`, WS `read_receipt` / #20 #21

#### F-CHAT-06 채팅방 나가기
- **설명:** 채팅방을 내 목록에서 숨긴다.
- **API / 이슈:** `POST /chat/rooms/{id}/leave` / #20

### 5.13 알림

#### F-NOTI-01 푸시 기기 등록
- **설명:** 로그인한 기기를 푸시 알림 대상으로 등록하고, 로그아웃하면 해제한다.
- **API / 이슈:** `PUT/DELETE /devices/{device_id}` / #22

#### F-NOTI-02 알림함
- **설명:** 받은 알림을 목록으로 보고, 하나씩 또는 전체 읽음 처리한다.
- **API / 이슈:** `GET /notifications`, `POST /notifications/read` / #22

#### F-NOTI-03 관심 단지·지역 새 거래 알림
- **설명:** 매일 수집이 끝나면 관심 단지·지역에 새로 올라온 거래를 **묶어서 한 번** 알려준다.
- **규칙:** 여기서 "새 거래"는 **새로 수집된 거래**다. 계약일이 최대 30일 전일 수 있으므로 알림에 계약일을 표시한다.
- **API / 이슈:** 내부 배치 / #22

#### F-NOTI-04 채팅 알림
- **설명:** 상대가 앱을 보고 있지 않을 때 새 메시지를 푸시로 알린다.
- **규칙:** 채팅 알림 설정이 꺼져 있으면 보내지 않는다.
- **API / 이슈:** 내부 처리 / #21 #22

#### F-NOTI-05 중개사 심사 결과 알림
- **설명:** 중개사 신청이 승인·반려되면 알린다(반려 사유 포함).
- **API / 이슈:** 내부 처리 / #22

#### F-NOTI-06 알림 수신 설정·광고성 동의
- **설명:** 채팅 알림, 관심 알림, 광고성 알림, 야간 광고성 알림을 각각 켜고 끈다.
- **규칙 (정보통신망법)**
  - 광고성 알림은 **동의한 사람에게만** 보낸다.
  - 밤 9시~아침 8시 광고성 알림은 **따로 동의**를 받는다.
  - 동의·철회한 날짜를 기록하고, **2년마다 다시 동의**를 받는다.
  - 광고성 알림 제목에는 `(광고)`를 붙인다.
- **API / 이슈:** `PUT /users/me/consents` / #16 #22

### 5.14 신고

#### F-RPT-01 신고하기
- **설명:** 매물, 채팅방, 사용자, 중개사를 신고한다.
- **신고 사유:** 허위 매물, 가격 오류, 스팸, 욕설·비방, 불법 중개, 기타
- **규칙:** 같은 대상을 두 번 신고할 수 없다.
- **API / 이슈:** `POST /reports` / #23

#### F-RPT-02 내 신고 처리 현황
- **설명:** 내가 한 신고가 처리됐는지 확인한다.
- **API / 이슈:** `GET /reports/me` / #23

#### F-RPT-03 신고 기반 임시 비노출
- **설명:** 믿을 만한 신고가 쌓이면 관리자 처리 전이라도 대상을 잠시 숨긴다.
- **규칙**
  - 신고 **건수가 아니라 신고자 신뢰도**로 판단한다(경쟁 업체가 계정 여러 개로 신고하는 것 방지).
  - 신뢰도 요소: 가입 기간, 과거 신고가 인정된 비율, 같은 기기·IP에서 대량 가입했는지 여부
  - 임시로 숨기는 건 **허위 매물 신고**에만 적용한다. 나머지는 관리자 확인 대기 목록의 우선순위만 올린다.
  - 점수 기준은 정책 결정 후 확정한다.
- **API / 이슈:** 내부 처리 / #23

- **API / 이슈:** `/admin/reports` / #23

#### F-ADM-03 용어 관리
- **설명:** 용어 해설을 추가·수정한다.
- **API / 이슈:** `PUT /admin/glossary/{term_id}` / #23

#### F-ADM-04 관리자 조치 기록
- **설명:** 관리자가 한 모든 조치(누가, 언제, 무엇을, 왜)를 기록하고 조회한다.
- **API / 이슈:** `GET /admin/audit-logs` / #23

### 5.16 매물 (3차)

#### F-LST-01 매물 등록
- **설명:** 승인된 중개사가 현재 팔고 있는 매물을 등록한다.
- **필수 입력 (공인중개사법 제18조의2 표시·광고 명시사항)**

| 구분 | 항목 |
|---|---|
| 공통 | 소재지, 면적, 가격, 매물 종류, 거래 형태 |
| 건축물 | 총층수, 사용승인일, 방향(기준 포함), 방·욕실 수, 입주 가능일, 주차 대수, 관리비 |
| 토지 | 지목 |
| 중개사무소 (자동 표시) | 사무소명, 소재지, 연락처, 등록번호, 대표자 |

- **규칙**
  - 필수 항목이 빠지면 등록할 수 없다.
  - 좌표는 서버가 주소로 계산한다.
  - 동·호수는 저장만 하고 **공개하지 않는다.**
  - 등록하면 바로 지도에 보인다.
- **API / 이슈:** `POST /listings` / #24

#### F-LST-02 매물 수정·삭제
- **설명:** 본인이 등록한 매물을 고치거나 지운다.
- **예외:** 다른 중개사의 매물 → 권한 없음
- **API / 이슈:** `PATCH/DELETE /listings/{id}` / #24

#### F-LST-03 매물 상태 변경
- **설명:** 판매중 / 예약중 / 거래완료로 바꾼다.
- **API / 이슈:** `PATCH /listings/{id}/status` / #24

#### F-LST-04 매물 자동 만료·연장
- **설명:** 오래 방치된 매물을 자동으로 숨긴다.
- **규칙:** 등록 후 **30일**이 지나면 자동으로 숨긴다. 중개사가 "아직 판매 중"을 확인(연장)하면 다시 30일 보인다.
- **이유:** 허위·방치 매물 방지
- **API / 이슈:** `POST /listings/{id}/renew`, 내부 배치 / #24

#### F-LST-05 매물 보기
- **설명:** 지도·목록에서 매물을 보고 상세 정보와 담당 중개사를 확인한다.
- **규칙:** 조회수는 같은 기기에서 24시간 내 여러 번 봐도 1번으로 센다.
- **API / 이슈:** `GET /listings`, `GET /listings/{id}` / #24

#### F-LST-06 매물 찜·거래완료 알림
- **설명:** 매물을 찜하고, 찜한 매물이 거래완료되면 알림을 받는다.
- **API / 이슈:** `/interests/listings` / #24

### 5.17 공통

#### F-SYS-01 요청 수 제한
- **설명:** 과도한 요청을 막는다.
- **규칙**
  - 비로그인: 기기당 분당 300회 / 로그인: 사용자당 분당 600회
  - 통신사 망에서 여러 사람이 같은 IP를 쓰므로 IP 기준 제한은 분당 3,000회의 비정상 방어용만 둔다.
  - 초과 시 "잠시 후 다시 시도" 응답과 대기 시간을 준다.
- **API / 이슈:** 전 API 공통 / #15

#### F-SYS-02 조회 결과 캐시
- **설명:** 실거래가처럼 하루 한 번 바뀌는 데이터는 변경이 없으면 다시 내려보내지 않는다.
- **API / 이슈:** 공개 조회 API 공통 / #15

#### F-SYS-03 서버 상태 확인
- **설명:** 외부에는 "정상 동작 중" 여부만, 내부망에는 DB·Redis·외부 API 상태까지 알려준다.
- **API / 이슈:** `GET /health`, `GET /internal/health/ready` / #5

## 6. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 성능 | 지도 마커 응답 500ms 이내(캐시 적중 시 100ms), 한 번에 최대 500개 마커 |

| 개인정보 | 탈퇴 즉시 파기, 광고성 정보 수신동의 기록·2년 재동의 |
| 법령 | 공인중개사법(매물 표시·광고), 개인정보보호법, 정보통신망법 준수 |
| 접근성 | 면적은 평 병기, 어려운 용어는 한 줄 쉬운 설명 제공 (40~50대 기준) |
| 개발 | API 키 없이 mock으로 개발·테스트 가능, 테스트 우선(TDD) |
